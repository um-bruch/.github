# Um:bruch

**Um:bruch ist ein unabhängiger Think Tank für gesellschaftlichen Wandel, Gesundheitsversorgung, Civic Tech und gemeinwohlorientierte Software.**

Wir veröffentlichen Analysen, Positionspapiere, offene Forschungsdaten und kleine Software-Prototypen. Der Schwerpunkt liegt auf nachvollziehbaren Argumenten, lokaler Ausführbarkeit und klaren Grenzen zwischen Forschung, Konzept und produktiver Nutzung.

Website: [um-bruch.org](https://um-bruch.org)

Projektübersicht: [um-bruch.org/projekte](https://um-bruch.org/projekte/)

## Research-Use Boundary

> [!IMPORTANT]
> Die medizinischen und diagnostischen Repositories sind Forschungs-, Analyse- und Konzeptsoftware. Sie ersetzen keine ärztliche Beratung, keine Leitlinie, keine regulatorisch geprüfte Medizinsoftware und keine produktive Versorgungssystem-Entscheidung.

## Arbeitsprinzipien

| Prinzip | Bedeutung |
|---|---|
| Offen nachvollziehbar | Quellen, Versionen und Code sollen prüfbar sein. |
| Forschung statt Heilsversprechen | Prototypen sind Analyse- und Diskussionswerkzeuge, keine medizinischen Produkte. |
| Local-first | Wo Software entsteht, soll sie möglichst lokal und datensparsam laufen. |
| Mehrsprachig anschlussfähig | Deutsch ist die primäre Arbeitssprache, englische Metadaten erleichtern internationale Auffindbarkeit. |
