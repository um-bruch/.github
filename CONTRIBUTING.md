# Contributing to Um:bruch

Thank you for your interest in contributing to Um:bruch! We welcome contributions across our research repositories, diagnostic models, and civic technology demonstrators.

## How to Contribute

### Reporting Bugs & Data Issues
1. Check if the issue has already been reported.
2. Open a new issue using the **Bug Report** template.
3. Provide environment details, reproduction steps, and expected vs. actual behavior.

### Proposing Enhancements
1. Open an issue using the **Feature Request** template.
2. Detail the motivation, target domain (e.g. statutory health regulations, civic commons), and proposed technical approach.

### Pull Requests
1. Fork or branch from `main` (or `master` for legacy branches).
2. Ensure code follows local project conventions and passes existing linters/tests.
3. Keep pull requests focused and atomic.
4. Include a concise summary and reference relevant issues.

## Research-Use Boundary

Software in the medical informatics and diagnostic domain (`system-medicine`, `multiaxial-diagnostic-system`, `verordnungsampel`) is intended strictly for scientific research, analysis, and proof-of-concept exploration. Do not submit contributions that claim regulatory medical device compliance without coordination.
