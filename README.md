# um-bruch/.github

Dieses Repository enthält das öffentliche Organisationsprofil und Community-Health-Dateien für [Um:bruch](https://github.com/um-bruch).

## Enthalten

| Pfad | Zweck |
|---|---|
| `profile/README.md` | Sichtbares Organisationsprofil auf `github.com/um-bruch` |
| `llms.txt` | Maschinenlesbarer Kurzkontext für Crawler, LLMs und Suchsysteme |

## Pflegehinweise

- Das Profil soll knapp erklären, wofür Um:bruch steht und welche Repositories öffentlich relevant sind.
- Neue öffentliche Repositories sollten im Profil und in `llms.txt` ergänzt werden.
- Deutsche Endnutzertexte verwenden echte Umlaute.
